[마중] 출소자 재사회화 온보딩 네비게이터

팀 여름아 부탁해 · KDT 해커톤 예선 D-5 · 세션 2026-07-05 · 의뢰 skwog

VERDICT단련 완료 — 4개 균열 전부 봉합

내부 합의 + 멘토 피드백만 있던 기획안을 4개 축(진입 경로 · 임팩트 논리 · 데모 정합성 · 지불 구조)에서 압박. 아이디어는 "출소자 챗봇"에서 "공단 직원 업무 AX(출소자 온보딩을 front로 갖는)"로 무게중심을 옮기며 단단해짐. 7/8 공단 인터뷰가 첫 외부 검증이며, 인터뷰 질문지가 확정 구조와 정합함을 확인.

LOCKED확정된 결정

  • 본체 = 공단 직원 AX. 반복 응대(계좌 재개설·휴대폰 재개통·제도 안내) 제거 + 상담 전 triage. 출소자 화면은 front, 직원 가치가 지불 논리.
  • 피치 언어: "앱뱅킹이 은행원을 없앤 게 아니라 창구 반복업무를 없앴다 — 마중은 공단의 앱뱅킹."
  • 진입 = A 쐐기 → B 확장. 공단 시설 내(재활 의지로 자기선별된 입소자)에서 시작, 출소 직후 오픈 챗봇은 확장 단계.
  • BM = 성과지표 3층. 단기(응대시간 절감·AI 1차 처리율·triage 완료율)=과금 근거 / 중기(신청 전환율 등, 인터뷰로 공단 실제 지표명 확보)=갱신 근거 / 장기(재복역률 6% vs 29%)=서사.
  • 예선 프로토타입 = 상황입력→급한일 정리→체크리스트→지도. 직원측 요약 카드는 본선 고려 + 기획안 로드맵 한 줄 + 인터뷰용 종이 목업.

KILLED기각된 것과 사유

  • 재범률 연동 성과 지불 — 측정 3년+, 인과 귀속 불가, SIB급 계약 무게. 심사 신뢰 역효과.
  • B(오픈 챗봇) 우선 진입 — "출소자가 어떻게 알고 쓰죠?"에 답 없음. 배포 경로 부재.
  • 직원 대시보드 예선 구현 — D-5 스코프 자멸. 본선 이월.

SURVIVED살아남은 약점 — 제출 전 처리

  • 가석방 통계(2024 약 48%) 1차 출처(교정통계연보) 미검증 — 확인 전 수치 단정 금지.
  • 디지털 단절 역설(셀프서비스를 가장 못 쓰는 집단에 셀프서비스 제공) 방어 논리가 기획안에 흩어져 있음 — A 쐐기 환경 + 체크리스트 장치로 명시할 것.
  • 기획안 ①②③ 기능 목록에 체크리스트 누락 / "출소 그다음 날부터" B 프레임 잔존 문구 — A 쐐기 기준 재작성.
