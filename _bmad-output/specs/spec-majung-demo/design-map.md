## 시안이 확정한 디자인 언어 (구현 시 준수)

- **네비게이션 바(하단 5탭)**: 홈 / 로드맵 / 상담(중앙 강조 FAB형) / 지도 / 내 정보 — 로드맵 화면 기준이 정본
- **챗봇 → 로드맵 연결**: 제도 카드의 "오늘의 할일에 추가" 버튼 = CAP-3 결과가 CAP-4 체크리스트로 흘러가는 seam
- **제도 카드 구성**: 제도명 + 신청 방법 + 바로가기 / 기관 카드: 지도 썸네일 + 전화번호 + 전화하기
- **기한 경고 패턴**(로드맵): "오늘 오후 6시 전에…" 주황 경고 박스
- **온보딩 선택지 패턴**: 큰 질문 1개 + 카드형 선택지 2~3개(보조 설명 포함) + 진행률 바(1/5)
- **톤**: "걱정 마세요", "오늘도 고생 많으셨어요" — 판단하지 않는 동행 톤 유지됨
