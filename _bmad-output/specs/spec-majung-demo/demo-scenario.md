# 데모 시나리오 — 시연 대본이자 테스트 픽스처

> CAP-2·CAP-3의 success 판정 기준. 7/8 인터뷰와 제출 영상 모두 이 대본으로 시연한다.

## 페르소나

**김판수(가명), 40대.** 5년 복역 후 출소, 무연고. 스마트폰 사용 서툼(디지털 단절). 공단 시설 입소 상태에서 태블릿/PC로 사용한다는 전제(A 쐐기).

## 시연 입력 3종과 기대 triage

| # | 입력 | 방식 | 기대 상위 영역 (2~3개) |
|---|---|---|---|
| 1 | "막 출소했어요" | 프리셋 | 신분 재건, 긴급복지·생계 |
| 2 | "잘 곳이 없어요" | 프리셋 | 주거, 긴급복지·생계 |
| 3 | "5년 살고 나왔는데 통장도 없고 휴대폰도 안 돼요. 뭐부터 해야 할지 모르겠어요" | 자유 입력 | 신분 재건(통장·휴대폰·신분증), 긴급복지·생계 |

판정: 기대 영역이 우선순위 상위에 포함되면 통과. 순서가 다르되 설명이 타당하면 허용.

## 메인 시연 경로 (입력 3 기준, 3~4분)

1. 진입 화면 → 자유 입력 3 타이핑
2. triage 결과: "지금 가장 급한 일" 2~3개 카드
3. 첫 카드(신분 재건) 선택 → 제도 안내: 제도명 + 어디서 + 필요 서류 + 다음 단계
4. "체크리스트로 보기" → 단계별 체크리스트 화면
5. 체크리스트 항목의 "위치 보기" → 지도(기관 마커 + 전화·운영시간)

## 쉬운 말 톤 규칙 (CAP-3 success 기준)

- 한 문장 = 한 지시. 행정용어는 풀어 쓴다 ("주민등록 재등록" → "주민센터에 가서 주민등록을 다시 살리는 신청").
- 근거 제도명은 괄호로 병기한다 — 신뢰 장치이자 상담사 연계 대비.
- 금지: 판단·훈계 톤("~하셨어야죠"), 죄종·전과 언급 요구, 재촉.
- 모든 안내 끝에 다음 행동 1개를 명시한다 ("내일 오전, ○○주민센터로 가세요").

## 지도 데모 데이터 (서울 서부 중심, 하드코딩 허용)

- 한국법무보호복지공단 서울서부지부 — 위치·대표전화·평일 09~18시
- 관할 주민센터 1곳, 고용센터 1곳 (실제 공개 정보 사용)
- 기관별 필드: 이름 / 주소 / 전화 / 운영시간 / 지도 마커
