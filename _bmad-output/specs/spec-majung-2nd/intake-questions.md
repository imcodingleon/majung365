## 0. 설계 원칙

**지원 항목마다 필수 문항을 하나씩 둔다.** 문항이 길어지더라도 필요한 정보를 다 받아서 정확한
안내를 준다. 분야마다 대표 문항 하나만 두고 나머지를 조건부로 숨기는 방식은 채택하지 않았다.
그렇게 하면 오늘 밤 잘 곳이 없으면서 부양가족도 있는 사람이 장기주거 안내를 받지 못한다.
**문항 하나를 줄이려다 가장 급한 사람을 놓치는 셈이다.**

분량 부담은 세 가지로 완화한다.

1. **모든 문항에 "잘 모르겠어요"를 둔다.** 단, **같은 역할의 선택지가 이미 있으면 중복해서 두지
   않는다**(Q2-2의 "신청했는지 잘 모르겠어요", Q6-3의 "확인 안 했어요"). 그리고 **"모르는 것"과
   "말하고 싶지 않은 것"은 구분한다**(Q6-2에 둘 다 있다)
2. **진행 정도를 항상 보여준다.** 분야 안에서는 "주거 3문항 중 2번째", 전체로는 "6개 분야 중
   3개 마쳤어요"
3. **분야 단위로 중간 저장한다.** 앱을 닫았다가 다시 열어도 이어서 답할 수 있다

**분야 완료 판정:** 화면에 실제로 노출된 문항을 모두 답하면 그 분야는 완료다. 꼬리질문에
노출 조건이 있으므로 필요한 문항 수는 사람마다 자동으로 달라진다.

### 문구 규칙

| # | 규칙 |
|---|---|
| ① | 문항과 선택지는 쉬운 말. 공식 제도명은 도움말에서 `공식 이름은 '~'예요`로 한 번만 |
| ② | 문항 안에 괄호로 공식 명칭을 넣지 않는다 |
| ③ | 선택지는 사용자 1인칭 진술. **예외: 죄목 대분류는 명사형을 유지한다** — 1인칭으로 바꾸면 자기 죄를 스스로 진술하는 문장이 된다 |
| ④ | `네,` 접두는 네 응답과 아니요 응답이 **둘 다 있는 선택지 집합에서만** 유지 |
| ⑤ | 선택지에서 쉬운 설명을 빼지 않는다. 도움말은 읽히지 않을 수 있다 |
| ⑥ | 저장값이 같아도 사용자가 자기 상황으로 알아볼 수 있게 나눠 쓴다 |
| ⑦ | **판단하는 어감을 쓰지 않는다.** `넘겼나요`·`아직` 같은 표현은 사용자가 잘못했다는 신호가 된다 |
| ⑧ | **사용자가 알 수 없는 것을 묻지 않는다.** 답할 수 없는 질문은 문항이 아니라 확인 사항이다 |
| ⑨ | 성격이 다른 것을 한 목록에 섞지 않는다 (희망·현재 상태·과거 이력) |
| ⑩ | 응급 선택지는 시각적으로 분리한다 |
| ⑪ | 같은 것을 두 번 묻지 않는다 |

## 2. 분야 1 — 주거 (R1 숙식제공 · R4 주거지원 · R11 주민등록 주소)

### Q1-1 · R1 숙식제공 [필수]
> **지금 머물 곳은 어떤 상황인가요?**

단일선택 · `dataKey = accommodationStatus`

| optionId | 선택지 |
|---|---|
| `NO_PLACE_TONIGHT` | 오늘 밤 잘 곳이 없어요 |
| `TEMPORARY_UNSTABLE` | 잠시 머물 곳은 있지만 곧 나가야 해요 |
| `CANNOT_LIVE_WITH_CONTACTS` | 가족이나 아는 사람이 있지만 함께 살 수 없어요 |
| `TRAINING_COMMUTE_DIFFICULT` | 직업교육 장소가 멀어 오가기 어려워요 |
| `STABLE_PLACE` | 계속 지낼 곳이 있어요 |
| `UNKNOWN` | 잘 모르겠어요 |

### Q1-1-1 · 임시 거처 종료일 [꼬리]
> **지금 머무는 곳은 언제까지 있을 수 있나요?**

노출 조건: Q1-1이 `NO_PLACE_TONIGHT` 또는 `TEMPORARY_UNSTABLE`
날짜 입력 · "잘 모르겠어요" 버튼 병행 · `dataKey = temporaryStayEndDate`

### Q1-2 · R4 주거지원 [필수]
> **가족과 오래 살 집을 구하려고 하나요? 맞는 것을 모두 골라주세요.**

복수선택 · `dataKey = housingConditionIds`

| optionId | 선택지 | 규칙 |
|---|---|---|
| `HAS_DEPENDENT_FAMILY` | 함께 살면서 내가 생활비를 대야 할 가족이 있어요 | |
| `ALL_HOUSEHOLD_HOMELESS` | 함께 살 가족 모두 자기 집이 없어요 | |
| `RESPONSIBLE_HOUSEHOLD_HEAD` | 내가 가족의 생활을 책임지고 있어요 | |
| `IMMEDIATE_SHELTER` | 오래 살 집보다 오늘 잘 곳이 먼저 필요해요 | 다른 조건과 함께 선택 가능 |
| `UNKNOWN` | 잘 모르겠어요 | `exclusive = true` |

### Q1-3 · R11 주민등록 주소 [필수]
> **지금 지내는 곳이 주민등록 주소와 같나요?**

단일선택 · `dataKey = addressStatus`
도움말: 늘 지낼 곳이 없다면 주민등록과 상관없이 '일정하게 지내는 곳이 없어요'를 골라주세요.

| optionId | 선택지 |
|---|---|
| `MATCHED` | 네, 지금 지내는 곳으로 되어 있어요 |
| `MISMATCHED` | 아니요, 예전에 살던 곳이나 다른 주소로 되어 있어요 |
| `INACTIVE_CONFIRMED` | 주민센터에서 주민등록 주소가 없거나 확인이 안 된다고 했어요 |
| `NO_FIXED_RESIDENCE` | 일정하게 지내는 곳이 없어요 |
| `UNKNOWN` | 잘 모르겠어요 |

`INACTIVE_CONFIRMED`는 주민센터·주민등록표·공식 서류로 확인된 경우에만 저장한다.
사용자의 추측을 이 값으로 바꾸지 않는다. **말소와 거주불명은 다른 상태이지만 저장값은
하나이며, 문구가 두 경우를 모두 포괄해야 한다.**

### Q1-3-1 · 전입신고 가능 여부 [꼬리]
> **지금 지내는 곳을 새 주민등록 주소로 신고할 수 있나요?**

노출 조건: Q1-3이 `MISMATCHED` · `dataKey = canRegisterCurrentResidence`
도움말: 공식 이름은 '전입신고'예요.
선택지: 이 주소로 신고할 수 있어요(`YES`) / 아는 사람 집이나 시설에 있어서 신고할 수 있는지
모르겠어요(`UNKNOWN`)

### Q1-3-2 · 전입신고 기한 경과 [꼬리]
> **전입신고 기한(14일)은 지났나요?**

노출 조건: Q1-3이 `MISMATCHED` 또는 `INACTIVE_CONFIRMED` · `dataKey = moveInReportOverdue`
선택지: 네 / 아니요 / 잘 모르겠어요

**`넘겼나요`로 쓰지 않는다.** 기한을 어겼다는 지적이 되어 규칙 ⑦에 어긋난다.

## 3. 분야 2 — 생계·긴급비용 (R2 공단 긴급지원 · R12 생계급여)

### Q2-1 · R2 공단 긴급지원 [필수]
> **지금 가장 급하게 필요한 돈은 어디에 쓰나요?**

단일선택 · `dataKey = emergencyExpenseType`

**표시 규칙: 앞의 넷을 먼저 보여주고, "그 밖의 비용"을 눌렀을 때 뒤의 셋이 펼쳐진다.**
뒤의 셋은 생활관 이용자·훈련 참여자·구직 활동자에게만 해당하므로 모두에게 보일 이유가 없다.

| optionId | 선택지 | 공식 지원내용 | 표시 |
|---|---|---|---|
| `LIVING_EXPENSE` | 밥값과 생활비가 필요해요 | 생계지원 3인 이상 가구 최대 20만원 | 기본 |
| `MEDICAL_EXPENSE` | 병원비가 필요해요 | 의료지원 최대 30만원 | 기본 |
| `HOUSING_EXPENSE` | 월세나 방 구할 돈이 필요해요 | 주거비용 5인 이상 가구 최대 30만원 | 기본 |
| `CHILD_EDUCATION` | 아이 학비와 학용품값이 필요해요 | 고교생 교육지원 최대 15만원 | 기본 |
| `FACILITY_BASIC_LIVING` | 생활관에서 지낼 기본 생활비가 필요해요 | 숙식기초생활 10만원 | 펼침 |
| `TRAINING_PREP` | 직업교육을 받는 동안 쓸 돈이 필요해요 | 직업훈련장려 20만원 | 펼침 |
| `JOB_SEARCH_PREP` | 일자리를 찾는 동안 쓸 돈이 필요해요 | 취업활동지원 20만원 | 펼침 |
| `UNKNOWN` | 잘 모르겠어요 | | 기본 |

금액을 화면에 낼 때는 **"최대 · 공식 페이지 기준 · 확인일"** 표시를 반드시 함께 낸다.
기부금 재원이라 지부 사정에 따라 금액이 적거나 지원이 불가능할 수 있다.

### Q2-1-1 · 직업교육 참여 상태 [꼬리]
> **지금 직업교육을 받고 있나요?**

노출 조건: Q2-1이 `TRAINING_PREP` · `dataKey = trainingParticipation`
선택지: 네, 받고 있어요 / 알아보는 중이에요 / 아니요, 받지 않아요 / 잘 모르겠어요

### Q2-1-2 · 구직 활동 상태 [꼬리]
> **일자리를 찾는 중인가요?**

노출 조건: Q2-1이 `JOB_SEARCH_PREP` · `dataKey = jobSearchActivity`
선택지: 네, 찾고 있어요 / 찾아볼 계획이에요 / 아니요, 지금은 아니에요 / 잘 모르겠어요

**두 꼬리질문은 준비물 안내에만 쓴다. 이 답으로 지원 대상에서 탈락시키지 않는다.**
기획서가 "질문을 추가해 탈락시키지 않는다"고 명시한 부분이다.

### Q2-2 · R12 생계급여 [필수]
> **정부가 매달 주는 생활비 지원을 신청했나요?**

단일선택 · `dataKey = livelihoodBenefitStatus`
도움말: 소득과 재산이 적은 집에 정부가 매달 생활비를 주는 제도예요. 공식 이름은 '생계급여'예요.

| optionId | 선택지 |
|---|---|
| `RECEIVING` | 지금 받고 있어요 |
| `PENDING` | 신청했고 결과를 기다리고 있어요 |
| `NOT_APPLIED` | 신청은 안 했어요 |
| `UNKNOWN` | 신청했는지 잘 모르겠어요 |
| `OPT_OUT` | 지금은 알아보고 싶지 않아요 |

### Q2-2-1 · 생활비 급한 정도 [꼬리]
> **지금 생활비가 얼마나 급한가요?**

노출 조건: Q2-2가 `PENDING` · `NOT_APPLIED` · `UNKNOWN` · `dataKey = livelihoodUrgency`
선택지: 오늘이나 며칠 안에 쓸 생활비가 없어요 / 매달 생활비가 계속 부족해요 / 두 가지 모두
맞아요 / 잘 모르겠어요

**첫 결과를 보여주기 전에 소득·재산 같은 민감한 금액을 입력하게 하지 않는다.**

## 4. 분야 3 — 신분·행정 (R9 신분증 · R10 통장)

### Q3-1 · R9 신분증 [필수]
> **지금 바로 쓸 수 있는 신분증이 있나요?**

단일선택 · `dataKey = identityStatus`
도움말: 주민등록증, 운전면허증, 사진이 붙은 임시 신분증을 말해요. 임시 신분증은 주민센터에서 받아요.
선택지: 네, 있어요(`USABLE_ID`) / 아니요, 없어요(`NOT_USABLE`) / 잘 모르겠어요(`UNKNOWN`)

### Q3-1-1 · 신분증 상세 [꼬리]
> **신분증은 지금 어떤 상태인가요?**

노출 조건: Q3-1이 `NOT_USABLE` · `dataKey = identityDetail`
도움말: 주민등록증을 신청한 다음 주민센터에 말하면 임시 신분증을 받을 수 있어요. 사진이 붙어
있고 30일 동안 쓸 수 있어요. 공식 이름은 '주민등록증 발급신청 확인서'예요.

| optionId | 선택지 |
|---|---|
| `PASSPORT_ONLY` | 날짜가 지나지 않은 여권만 있어요 |
| `REISSUE_APPLIED` | 주민등록증은 신청했지만 임시 신분증은 받지 않았어요 |
| `REISSUE_NOT_APPLIED` | 주민등록증은 신청 안 했어요 |
| `REGISTRATION_INACTIVE` | 주민센터에서 주민등록 주소가 없거나 확인이 안 된다고 했어요 |
| `UNKNOWN` | 잘 모르겠어요 |

**중복 처리(규칙 ⑪):** `REGISTRATION_INACTIVE`는 Q1-3의 `INACTIVE_CONFIRMED`와 같은 문항이다.
**Q1-3에서 이미 답했으면 이 선택지를 빼고 "주소 문제는 이미 확인했어요"로 대체한다.**
같은 것을 두 번 묻지 않는다.

### Q3-2 · R10 통장 [필수]
> **내 이름으로 된 통장을 지금 쓸 수 있나요?**

단일선택 · `dataKey = bankAccountStatus`
도움말: 지원금을 받고 필요할 때 돈을 찾거나 보낼 수 있는 통장을 말해요.
선택지: 지금 쓸 수 있어요(`USABLE`) / 통장은 있지만 쓰기 어려워요(`UNUSABLE`) / 내 이름으로 된
통장이 없어요(`NONE`) / 잘 모르겠어요(`UNKNOWN`)

### Q3-2-1 · 통장 사용 문제 [꼬리]
> **통장을 쓸 때 어떤 점이 어려운가요?**

노출 조건: Q3-2가 `UNUSABLE` · `dataKey = bankAccountDetail`
선택지: 하루에 보낼 수 있는 돈이 너무 적어요(`LIMIT_RESTRICTED`) / 은행에서 통장을 막아
두었어요(`BANK_RESTRICTED`) / 빚 때문에 통장에 있는 돈을 쓸 수 없어요(`SEIZED`) / 이유를 잘
모르겠어요(`UNKNOWN`)

### Q3-2-2 · 통장 개설 상태 [꼬리]
> **통장은 지금 어떤 상태인가요?**

노출 조건: Q3-2가 `NONE` · `dataKey = bankAccountDetail`
선택지: 통장을 새로 만들려고 해요(`FIRST_OPEN`) / 은행에서 새 통장을 만들 수 없다고
했어요(`OPENING_REJECTED`) / 빚 때문에 새 통장도 막힐까 걱정돼요(`SEIZURE_WORRY`) / 가족
이름으로 된 통장만 쓸 수 있어요(`FAMILY_ONLY`) / 잘 모르겠어요(`UNKNOWN`)

**R10 결과 카드의 준비물 안내에 본인 명의 휴대폰 확인이 들어가야 한다.** 휴대폰 개통을 별도
지원 항목으로 만들지 않기로 했지만, 통장 개설의 선행조건은 정확히는 *본인 명의* 휴대폰이고
앱은 타인 명의 기기로도 쓸 수 있다.

## 5. 분야 4 — 취업·직업 (R6 취업·허그일자리 · R7 창업지원)

### Q4-1 · R6 현재 상태 [필수]
> **지금 일을 하고 있나요?**

단일선택 · `dataKey = employmentCurrentStatus`

| optionId | 선택지 |
|---|---|
| `SEEKING` | 아니요, 일을 찾고 있어요 |
| `EMPLOYED_BUSINESS_STUDENT` | 네, 일하거나 사업을 하거나 학교에 다녀요 |
| `GOVERNMENT_JOB_OR_UNEMPLOYMENT_BENEFIT` | 정부 일자리 사업에 다니거나 실업급여를 받고 있어요 |
| `UNKNOWN` | 잘 모르겠어요 |

**원안은 희망·현재 상태·과거 이력 8개를 한 목록에 섞어 두었다(규칙 ⑨ 위반).** 지금 일하면서
직업교육도 받고 싶은 사람이 무엇을 골라야 할지 알 수 없었다. 두 단계로 나눴다.

### Q4-1-1 · R6 필요한 도움 [꼬리]
> **일자리 문제로 어떤 도움이 필요한가요?**

노출 조건: Q4-1이 `SEEKING` 또는 `GOVERNMENT_JOB_OR_UNEMPLOYMENT_BENEFIT`
`dataKey = employmentSupportNeed`
선택지: 바로 일자리를 찾고 싶어요(`JOB_NOW`) / 직업교육을 받고 일하고
싶어요(`TRAIN_AND_WORK`) / 상담부터 교육, 일자리까지 차례로 도움받고 싶어요(`STAGED_SUPPORT`) /
직업교육만 받고 싶어요(`TRAINING_ONLY`) / 잘 모르겠어요(`UNKNOWN`)

### Q4-1-2 · 허그일자리 참여 이력 [꼬리]
> **허그일자리에 참여해 본 적 있나요?**

노출 조건: Q4-1-1과 같음 · `dataKey = hugJobHistory`
선택지: 네 / 아니요 / 잘 모르겠어요

허그일자리 재참여 자격 판정에 쓰인다. 희망 사항과 섞으면 안 되는 과거 이력이다.

### Q4-2 · R7 창업지원 [필수]
> **장사나 사업을 시작하려고 하나요?**

단일선택 · `dataKey = startupIntent`

| optionId | 선택지 |
|---|---|
| `PREPARING` | 네, 준비하고 있어요 |
| `INTERESTED_NO_PREP` | 관심은 있는데 준비한 것은 없어요 |
| `NOT_INTERESTED` | 아니요, 지금은 생각이 없어요 |
| `UNKNOWN` | 잘 모르겠어요 |

### Q4-2-1 · 창업 준비 상태 [꼬리]
> **장사나 사업을 하려고 준비한 것을 모두 골라주세요.**

노출 조건: Q4-2가 `PREPARING` · 복수선택 · `dataKey = startupReadinessIds`
선택지: 관련 자격증이 있거나 같은 일을 1년 이상 해봤어요(`SKILL_OR_EXPERIENCE`) / 창업교육을
받았어요(`STARTUP_TRAINING`) / 사업할 곳을 정했어요(`LIVING_BASE`) / 내가 낼 돈을 준비할 수
있어요(`OWN_FUNDS`)

**원안은 선택지 9개였고 뒤의 둘이 특히 나빴다(규칙 ⑧ 위반).**

| 뺀 선택지 | 이유 |
|---|---|
| 빚 문제로 법원의 채무불이행자 명부에 올라간 적이 **없어요** | 부정형이고 용어를 모른다 |
| 지원에서 제외되는 업종이 **아니에요** | 제외 업종 목록을 모르면 답할 수 없다 |

**이 둘은 결과 카드의 "먼저 확인할 것"으로 내렸다.** 사용자가 답하는 대신 읽기만 하면 된다.
기획서도 "자동으로 지원 불가를 확정하지 않는다"고 했으므로 문항에서 받아야 할 값이 아니다.
자격증과 1년 이상 경력은 둘 다 "이 일을 할 줄 안다"를 확인하므로 하나로 합쳤다.

**창업 생각이 없는 사람은 한 번 누르고 끝난다.** 원안은 9개를 읽어야 했다.

## 6. 분야 5 — 건강·심리 (R3 기초건강지원 · R8 심리상담)

### Q5-1 · R3 기초건강지원 [필수]
> **지금 어떤 건강 도움이 필요한가요?**

단일선택 · `dataKey = healthSupportNeed`

**표시 규칙(규칙 ⑩): `IMMEDIATE_TREATMENT`를 목록 맨 위에 두고 색이나 구분선으로 떼어 놓는다.**
이 답 하나만 119·응급실 즉시 안내로 가고 나머지 여섯과 처리가 다르다.

| optionId | 선택지 |
|---|---|
| `IMMEDIATE_TREATMENT` | **지금 바로 치료받아야 해요** |
| `TREATMENT` | 병원 진료나 치료가 필요해요 |
| `MEDICATION` | 약이 필요해요 |
| `HEALTH_CHECKUP` | 건강검진을 받고 싶어요 |
| `MENTAL_HEALTHCARE` | 우울하거나 불안해서 병원 진료가 필요해요 |
| `FAMILY_HEALTHCARE` | 가족의 병원비나 치료 도움이 필요해요 |
| `UNKNOWN` | 잘 모르겠어요 |

`IMMEDIATE_TREATMENT`는 결과를 기다리게 하지 않는다.

### Q5-2 · R8 심리상담 [필수]
> **마음이 힘들 때 어떤 도움부터 받고 싶은가요?**

단일선택 · `dataKey = counselingNeed`
선택지: 상담사와 1:1로 이야기하고 싶어요(`INDIVIDUAL`) / 다른 사람들과 함께 상담받고
싶어요(`GROUP`) / 심리검사를 받고 결과 설명도 듣고 싶어요(`ASSESSMENT`) / 병원이나 전문
상담기관을 연결받고 싶어요(`MEDICAL_REFERRAL`) / 가족도 함께 상담받고 싶어요(`FAMILY`) / 잘
모르겠어요(`UNKNOWN`)

## 7. 분야 6 — 기타·권리구제 (R13 수용·출소증명서 · R14 개인회생·파산 · R15 의료급여·건강보험)

### Q6-1 · R13 수용·출소증명서 [필수]
> **교도소·구치소에 있던 기간과 출소일이 적힌 증명서가 있나요?**

단일선택 · `dataKey = releaseCertificateStatus`
도움말: 공식 이름은 '수용·출소증명서'예요. 형사사법포털이나 가까운 교도소·구치소에서 받을 수 있어요.
선택지: 있어요(`READY`) / 지금 받는 중이에요(`PENDING`) / 없어요(`NONE`) / 잘
모르겠어요(`UNKNOWN`)

### Q6-2 · R14 개인회생·파산 [필수]
> **빚 문제는 지금 어떻게 하고 있나요?**

단일선택 · `dataKey = debtProcedureStage`

| optionId | 선택지 |
|---|---|
| `STARTING` | 처음 알아보는 중이에요 |
| `COURT_PROCESS` | 법원에 개인회생이나 파산을 신청해 진행 중이에요 |
| `CCRS_PROCESS` | 신용회복위원회에서 빚 조정을 진행 중이에요 |
| `STOPPED` | 신청했는데 중간에 멈췄거나 안 됐어요 |
| `UNKNOWN` | 잘 모르겠어요 |
| `OPT_OUT` | 답하고 싶지 않아요 |

`UNKNOWN`과 `OPT_OUT`을 모두 둔다(규칙 ⑥). **모르는 것과 말하고 싶지 않은 것은 다르며,
채무는 민감한 주제라 말하지 않을 선택지가 반드시 있어야 한다.**

### Q6-2-1 · 정기 소득 [꼬리]
> **월급, 연금, 직접 일해서 버는 돈처럼 매달 들어오는 돈이 있나요?**

노출 조건: Q6-2가 `STARTING` · `dataKey = incomeContinuity`
선택지: 꾸준히 있어요(`REGULAR`) / 일용직처럼 들쑥날쑥해요(`IRREGULAR`) / 지금은
없어요(`NONE`) / 잘 모르겠어요(`UNKNOWN`)

**"장사로 버는 돈"으로 좁히지 않는다.** 프리랜서 수입이 빠지면 개인회생 자격 판정이 틀어진다.
**첫 결과 전에 채무액·채권자 수·재산 금액을 입력받지 않는다.**

### Q6-3 · R15 의료급여·건강보험 [필수]
> **출소 후 병원비를 줄여주는 보험이나 지원을 확인했나요?**

단일선택 · `dataKey = medicalCoverageStatus`
도움말: '의료급여'는 생활이 어려운 사람의 병원비를 정부가 도와주는 제도예요. 건강보험이 직장
가입인지 지역 가입인지는 몰라도 괜찮아요.

| optionId | 선택지 |
|---|---|
| `MEDICAL_AID` | 병원비 지원(의료급여)을 쓰고 있어요 |
| `HEALTH_INSURANCE` | 건강보험을 쓰고 있어요 |
| `PENDING` | 신청하거나 바꾸는 중이에요 |
| `UNCHECKED` | 확인 안 했어요 |
| `BLOCKED_CONFIRMED` | 병원이나 건강보험공단에서 쓸 수 없다고 했어요 |

`병원비 지원(의료급여)`에서 쉬운 설명을 빼지 않는다(규칙 ⑤). 도움말에 설명이 있어도
**선택지만 읽고 고르는 사용자가 많다.**

"잘 모르겠어요"를 따로 두지 않는다. `UNCHECKED`가 같은 역할을 한다(규칙 ①).

## 9. 아직 확정되지 않은 것

1. **`optionId` 값** — 기획 검토 중이다. 확정 전에는 코드에 고정값으로 박지 않는다
2. **Q1-2의 복수선택 5개가 저리터러시 사용자에게 부담일 수 있다.** 화면에서 나누어 보여줄지
   검토가 필요하다. Q4-2-1은 4개로 줄여 해소했다
3. **분야 순서** — 지금은 설문 흐름도의 순서를 그대로 따랐다. 출소 직후 급한 순서와 일치하는지
   확인이 필요하다
