1. 스킬 `diagram-design` 사용 (설치 완료 · `~/.claude/skills/diagram-design/`)

3. 검증: `python -m http.server 8099` → Playwright로 `svg` 요소만 스크린샷
   - `file://`는 차단되므로 반드시 HTTP로 띄울 것
4. 이미지 추출: PNG(권장) + JPG. **문서 삽입용 고해상도**가 필요하면
   `.wrap{max-width:1240px}` → `2480px`로 올리고 캡처 후 되돌린다

### 한글 렌더링 주의 (실수했던 지점)
Geist / Geist Mono / Instrument Serif에는 **한글 글리프가 없다.** 폰트 스택에 반드시 fallback을 넣을 것:
```
title : 'Instrument Serif','Noto Serif KR',serif
sans  : 'Geist','Noto Sans KR',sans-serif
mono  : 'Geist Mono','Noto Sans KR',monospace
```
화살표 라벨·기술 서브라벨은 **영문 유지**(MASKED, RETRIEVE, O/X/△/?)가 더 깔끔하다.
